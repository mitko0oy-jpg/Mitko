# Литературни досиета – генератор на книгата-игра

Прави PDF (формат B5, 176 × 250 мм) в два варианта: **ученическо копие** и **копие с решения**.
Съдържанието и картинките са платени и **не са в git** – стоят например в `private/dossiers10/`.

```
node scripts/dossiers/build.mjs private/dossiers10/content            # цялата книга → private/dossiers10/out/
node scripts/dossiers/build.mjs private/dossiers10/content --check    # само проверка на данните
node scripts/dossiers/build.mjs private/dossiers10/content --dossiers 5,6 --png-dossiers --out /tmp/prev
                                                                       # бърз преглед на отделни досиета (PNG)
```

Генераторът сам:
- подрежда думите в решетката 10 × 10 (→ ↓ ↘ ↗) така, че **неоградените букви, прочетени ред по ред, дават скритата следа**; всяка дума се чете точно веднъж;
- слага буквите пред отговорите в задача 3 така, че верните да дават кода; грешните букви и редът на отговорите се избират сами;
- проверява, че жълтата буква на всеки код е точната буква от тайното послание (досие N → поле N, финалът → последното поле);
- прави преговорите (следи, думи, автори), финала, страниците с отговори, номерата на страниците и препратките;
- съобщава, ако нещо не се побира на страницата (`Съдържанието не се побира`).

Нужни са Node 20+ и Playwright (`require("playwright")`).

## Папката със съдържание

```
private/dossiers10/
  assets/   cover.jpg, desk.jpg, magnifier.png, folder.png, cryptex.png, badge.png, notebook.png, chest.png,
            fonts/sofia-sans-{cyrillic,latin}-{400..900}-normal.woff2
  content/  book.json, dossiers/01.json … 27.json
  out/      готовите PDF файлове
```

## book.json

| Поле | Какво е |
|---|---|
| `name` | име на файловете, напр. `Literaturni-dosieta-NVO10` |
| `series`, `footTag`, `badge`, `gradesText`, `coverLine`, `missionTitle`, `backStamp`, `backLine` | текстове по корицата и долния ред |
| `message` | тайното послание; букви = брой досиета + 1 |
| `exampleDossier` | досието, показано като пример в помощните страници |
| `ranks` | четирите ранга в картата на детектива |
| `reviews` | преговори: `{title, after, from, to, more, moreExample}` – след досие `after`, за досиета `from`–`to` |
| `final` | `{code, yellow, works: [5 номера на досиета]}` – „Кой е написал…?“ |
| `applyExamples`, `favoriteExample`, `notes`, `tempoNote` | примерни отговори и бележки за родителя |

## Едно досие (`dossiers/NN.json`)

```json
{
  "no": 1,
  "grade": 9,
  "author": "Автор",
  "title": "Заглавие без кавички",
  "part": "Глава или откъс (по желание)",
  "icon": "magnifier | folder | cryptex | notebook | chest | badge (по желание)",
  "summary": "2–3 изречения, до 330 знака.",
  "gloss": [["Понятие", "кратко обяснение"]],
  "stars": [
    {"w": "ДУМА", "q": "Въпрос за задача 2, чийто отговор е тази дума"},
    {"w": "…", "q": "…"},
    {"w": "…", "q": "…", "a": "по желание: как да се покаже отговорът"}
  ],
  "bonus": ["10–15 думи, свързани с творбата; генераторът избира колкото са нужни"],
  "trace": "скритата следа – кратък цитат или фраза, 10–30 букви",
  "code": "ПЕТБУКВЕНА ДУМА",
  "yellow": 3,
  "mc": [
    {"q": "Въпрос (до 120 знака)", "a": "верен отговор (до 78 знака)", "w": ["грешен", "грешен"]}
  ],
  "t4": {"type": "order | groups | quote | who | match", "…": "вижте по-долу"},
  "t5": {"q": "Въпрос", "start": "Начало на тезата…", "example": "Примерна теза."}
}
```

- `mc` – точно 5 въпроса; буквата пред верния отговор на въпрос i е i-тата буква на `code`.
- `yellow` – коя буква от кода отива в тайното послание.
- Думите в решетката са само с главни букви, без интервали и тирета, до 10 букви.

### Задача 4 (бонус)

| `type` | Полета |
|---|---|
| `order` | `items`: 5 случки **в правилния ред** (генераторът ги разбърква) |
| `groups` | `heads`: 2 заглавия, `answer`: 2 списъка с думи |
| `quote` | `lines`: `[{"text": "… ___ …", "a": "дума"}]`, `extra`: излишни думи (по желание) |
| `who` | `lines`: `[{"text": "реплика", "a": "име"}]`, `extra`: още имена (по желание) |
| `match` | `pairs`: 3–5 `{"l": "понятие", "r": "пример"}` |

`title` и `prompt` в `t4` заменят стандартните заглавие и указание.
