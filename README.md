# Еду БЕЛ

Образователна платформа по български език и литература за 5., 6. и 7. клас: литературни карти с преговор през интервали, тренажор и AI коуч за задачата с разширен свободен отговор, разговори с героите от творбите, входен тест и отчет за родителя.

- Код: Netlify (статични страници в `public/`, API в `netlify/functions/`, Postgres миграции в `netlify/database/migrations/`).
- Съдържанието не е в това хранилище – то се зарежда в базата данни.
- Подробности за разработка: [CLAUDE.md](CLAUDE.md).
