# Проучвания и план „Еду БЕЛ 2.0“ (ноември 2026)

- `gen-alpha.md` – какво харесват 11–14-годишните (България, Европа), визия и мотивация.
- `strategy-research.md` – цени, пазар, растеж, право (ЕС/БГ).
- `navigation-parents.md` – подредба на приложението (Днес · Път · Бележник · Аз), „не бебешко“, изглед за родителя, насоки на ЕК (DSA чл. 28).
- `adaptive-learning.md` – как Ерчо избира задачите: умения, Ело/EMA, цел ~75–80% верни, преговор, варианти срещу наизустяване, псевдокод.
- `voice-audio.md` – глас навсякъде, аудио уроци, говорещи герои, хостинг (Cloudflare R2), цени.
- `plan/` – изходният код на страницата с плана (`python3 -I plan/build.py public/media plan/plan.src.html out.html`).

Фактите са с източници; „НАША ПРЕПОРЪКА“ са изводи, не данни. Кликаемият модел за теста с деца е в `docs/prototip/` (с примерни задачи, писани само за модела – не е платено съдържание).
