# Пилот – рекламен автопилот

Приложение за анализ, контрол и автоматизация на рекламните акаунти в Мета с фокус върху **реалния марж** (минимум 25–30%) при продажби с наложен платеж в България, Словакия, Словения и Унгария.

- **Табло** – марж след реклама по реалните поръчки (без ДДС, с върнатите пратки), MER, цена на поръчка, пари по дни, акаунти.
- **Кампании** – бюджети и паузи с едно натискане, сигнали за умора, разнообразие и таван на бюджета.
- **Креативи** – умора и „дни живот“, резерви, разнообразие по Андромеда, какво печели, карта на идеите.
- **Студио** – нови концепции, които не повтарят правеното, проверка на твърденията и AI етикета, генериране на видео.
- **Автопилот** – 18 правила, 3 режима (наблюдение / втори пилот / автопилот), граници, стоп, „върни 24 ч“, дневник.
- **Пазар** – възход / спад / шок / скъп аукцион по държави, новини, календар (празници, пенсии, Черен петък), проследяване, конкуренти от библиотеката с реклами.
- **Обучение** – оценка на всяко решение, доверие в правилата, технологичен радар.

Проучването, на което стъпва всичко: [docs/PROUCHVANE.md](docs/PROUCHVANE.md).

## Пробвай веднага (демо)

Отвори приложението с `?demo=1` – работи с примерни данни в браузъра, нищо не се променя в Мета.

## Локално

```
npm install
node scripts/dev-server.mjs 8899      # парола: local-pilot-password, демо данни
npm test
```

`/__job/sync` и `/__job/daily` пускат планираните задачи на ръка.

## Пускане с истинските акаунти

Отделен Netlify проект от това хранилище с **Base directory = `pilot`**, Netlify Database и AI Gateway включени. Настройки (env) в Netlify:

| Променлива | Задължителна | За какво |
|---|---|---|
| `APP_PASSWORD` | да | парола за вход (поне 10 знака) |
| `META_TOKEN` | да | токен на системен потребител: ads_read, ads_management, business_management, pages_show_list, pages_read_engagement |
| `META_APP_SECRET` | препоръчва се | `appsecret_proof` и подпис на уебхуците |
| `SALES_URL`, `SALES_TOKEN` | едното от двете | поръчки от ConvertBuilder във формат v1 |
| `SALES_HOOK_SECRET` | | уебхук `POST /api/hook/orders` |
| `META_WEBHOOK_VERIFY` | | уебхук на Мета `/api/hook/meta` (creative_fatigue и др.) |
| `FAL_KEY`, `FAL_MODEL_<ID>` | | видео модели през fal.ai |
| `SERPAPI_KEY` | | Google Trends |
| `AI_MODEL` | | по подразбиране `claude-opus-5-5` |
| `META_API_VERSION` | | по подразбиране `v27.0` |
| `PILOT_DEMO=1` | | сървърът да работи с демо данни |

Тайните никога не влизат в кода. Подробни стъпки: раздел 13 в проучването.
