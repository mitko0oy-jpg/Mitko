# Здравец Натура – новият сайт в ConvertBuilder (zdravets.eu)

Сайтът е направен като сайта за картите (edubel.bg): всяка страница в ConvertBuilder съдържа само
един елемент „Код“ с един ред, а самата страница идва от тази папка.

```
<script src="https://cdn.jsdelivr.net/gh/mitko0oy-jpg/Mitko@4acc18f7bd8bc44591414dc72c50ea93741667a1/landing/zdravets/load.js" data-zn="ИМЕ"></script>
```

| Страница в ConvertBuilder | Адрес | `data-zn` |
|---|---|---|
| Начало (нов сайт) – за преглед, после става началната | `/nachalo` | `nachalo` |
| Черен петък | `/cheren-petak` | `cheren-petak` |
| Продукти | `/produkti` | `produkti` |
| Продукт (един за всички, `?p=gel`, `?p=vein` …) | `/produkt` | `produkt` |
| Поръчка: блок над формата + формата „Чекаут на количка“ + блок под нея | `/poruchka` | `poruchka`, после `dolu` |
| Благодарим (нов сайт) – благодарствената страница на формата | `/blagodarim` | `blagodarim` |
| Доставка | `/dostavka` | `dostavka` |
| Контакти | `/kontakti` | `kontakti` |
| Общи условия (нови) | `/obshti-usloviya` | `obshti-usloviya` |
| Поверителност (нова) | `/poveritelnost` | `poveritelnost` |

На всички тези страници хедърът и футърът на сайта са скрити (бутон „Скрий“) – менюто и долната
част идват от блока.

## Поръчките

Количката и поръчката са тези на магазина в ConvertBuilder, затова всяка поръчка влиза в
ConvertBuilder → Магазин → Поръчки и оттам в OrderDesk. Бутоните добавят продукта в количката на
магазина и водят към `/poruchka`.

Продуктите в магазина, които сайтът ползва (номерата са в `zdravets/src/assets/data.js`):

| 25 | 2 гела за стави BeeVenom (скрит) | 22,90 € |
| 26 | 3 гела за стави BeeVenom (скрит) | 24,90 € |
| 27 | Комплект „Пълна грижа“: 3 гела + спрей (скрит) | 36,90 € |
| 28 | 3 крема BeeVenom за кожа (скрит) | 24,90 € |
| 29 / 30 / 31 | Хиалуронов крем / спрей / пластири – специална цена към поръчка (скрити) | 7,90 / 9,90 / 4,90 € |
| 32 | Подарък: 12 билкови пластира BeeHerb (скрит, добавя се сам до края на Черния петък) | 0 € |
| 4–12, 21–23 | Съществуващите продукти (крем за кожа, спрей, пластири, вени, GHK, хиалуронов, нокти) | както са в магазина |

Цената в `data.js` трябва да е същата като в магазина: магазинът смята сумата, сайтът само я показва.

## Нова версия

```
node scripts/build-zdravets.mjs        # zdravets/src → landing/zdravets/*.html
git commit … && git push                 # блоковете трябва да са в GitHub
node scripts/live-zdravets.mjs         # записва commit-а във version.txt
git commit … && git push                 # сайтът се сменя до 5 минути, без ConvertBuilder
```

Промените се правят в `zdravets/src/` (страници в `pages/`, данни и цени в `assets/data.js`,
логика в `assets/app.js`, вид в `assets/style.css`, формата за поръчка в `assets/checkout.css`).
Репото е публично: в него няма себестойности и нищо тайно.
