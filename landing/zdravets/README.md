## Поръчките

Количката и поръчката са тези на магазина в ConvertBuilder, затова всяка поръчка влиза в
ConvertBuilder → Магазин → Поръчки и оттам в OrderDesk. Бутоните добавят продукта в количката на
магазина и водят към поръчката (`links.checkout` в `data.js`).

Как се вдига сумата на поръчката:
- **Към 3 гела** – горе на поръчката, при 1 или 2 гела в количката.
- **Бъмп оферти** – отметки точно над бутона „Завърши поръчката“ (`BUMPS` в `data.js`, продукти 30 и 31).
- **Ъпсел и даунсел** – само във фунията `/kasa`: след „Завърши поръчката“ идва хиалуроновият крем за
  7,90 €, при „Не, благодаря“ – за 5,90 €, после „Благодарим“ (`UPSELL` в `data.js`). Нашите бутони
  натискат елемента „Ъпсел / Даунсел“ под блока; той добавя крема към вече приетата поръчка.
  Ако кремът вече е в поръчката или в нея няма нищо за ставите, двете страници се прескачат сами.
  Елементът „Ъпсел / Даунсел“ се появява в списъка с елементи само на стъпка, добавена с
  „+ Добави ъпсел или даунсел“ под стъпката с формата.

## Нова версия

```
node scripts/build-zdravets.mjs        # zdravets/src → landing/zdravets/*.html
git commit … && git push                 # блоковете трябва да са в GitHub
node scripts/live-zdravets.mjs         # записва commit-а във version.txt
git commit … && git push                 # сайтът се сменя до 5 минути, без ConvertBuilder
```

Промените се правят в `zdravets/src/` (страници в `pages/`, данни и цени в `assets/data.js`,
логика в `assets/app.js`, вид в `assets/style.css`, формата за поръчка в `assets/checkout.css`).
Репото е публично: в него няма себестойности и нищо тайно.
